# Yannz Portfolio

Static export of the portfolio artifact, deployed to the Vercel project `my-portfolio-1`.

- `index.html` – page shell and portfolio data (`#pf-data`)
- `style.css`, `app.js` – page styles and script
- `car.json` – 3D car model (base64 GLB), loaded by `app.js`

The Vercel deployment serves `index.html` and proxies the other files from this folder via jsDelivr.
