TAHAP 2 - MESIN PLUGIN (registry)
---------------------------------
  - library/registry.js memuat semua file di plugins/ secara rekursif. Satu file = satu fitur.
  - Dukung DUA format plugin:
    a) feature({ id, name, aliases, category, description, usage, permission, cooldown, limit,
       run(ctx) }) -> format internal yang ringkas.
    b) format Yann AI V15 / Lena AI:
         let handler = async (m, { sock, text, command, prefix, isCreator, Reply }) => { ... }
         handler.command = ['nama','alias']; handler.category='fun'; handler.owner=true; dll.
       -> dibungkus adapter jadi fitur. Sediakan m.reply, sock(=conn=lena=alip), dan helper
       global: isRegistered, isPrem, checkLimit, addLimit.
  - Menu dibuat OTOMATIS dari daftar fitur (nama, kategori, deskripsi) di source/yannai-menu.js.
  - Sediakan contoh plugin plugins/contoh/halo.js yang bisa disalin.


TAHAP 3 - ALUR PESAN (yannai-cmd.js)
------------------------------------
Urutan tiap pesan masuk:
  serializer (m) -> hook onMessage (afk, antilink, auto-ai, dll.) -> kalau command:
  cek lisensi aktif -> cek maintenance -> cek izin (user/premium/admin/owner) -> cek scope

TAHAP 4 - KONEKSI + LISENSI (yannajah.js, library/license.js, connection.js)
---------------------------------------------------------------------------
  - Start: banner -> validasi config -> login ke web database (nomor bot + password bot) ->
    database lokal -> muat plugin -> handler -> koneksi WhatsApp (QR / pairing code) -> heartbeat.
  - Pairing: pilih 1 (QR) atau 2 (pairing code). Dukung input dari console panel Pterodactyl
    (deteksi env P_SERVER_UUID / BOT_CONSOLE_INPUT), bukan cuma TTY.
  - custompairing dari settingsbot.js (default 8 huruf, mis. "YANNAJAH").
  - LicenseClient: verifyStored (pakai token tersimpan), login (nomor+password -> token),
    heartbeat berkala (terima status ban/disable/maintenance). Token disimpan file 0600.
  - Gagal aman: kalau web database tidak bisa dihubungi > grace (default 0) -> bot terkunci.
    Error 5xx/429/DATABASE_UNAVAILABLE dianggap gangguan sementara: token TIDAK dibuang,
    cek ulang tiap 30 detik, bot jalan lagi otomatis saat pulih. Tampilkan pesan jelas di console.
  - Alamat web database: library/license-endpoint.js. Development pakai LICENSE_SERVER_URL (.env);
    build menanam alamat tetap di yannajah.js (lihat TAHAP 8).


TAHAP 5 - settingsbot.js (GAYA Yann AI V15)
-------------------------------------------
Isi file ini PERSIS gaya settings.js Yann AI V15: variabel global.xxx = nilai, komentar pendek,
urutan: info bot, tempatDB, custompairing, harga, premku, sewa, limitHarian, warnGrup, SUBDO CF,
rest api, PANEL SETTING, link, delay, saluran, payment, image, mess. Contoh baris penting:
  global.owner='62xxxx'; global.namaOwner='...'; global.botname='...'; global.packname='...';
  global.author='...'; global.custompairing='YANNAJAH'; global.prefix=['.','!','#','/'];
  global.limitHarian=10; global.warnGrup=3; global.image={menu,welcome,left,reply,qris};
  global.mess={limit,owner,verifikasi,admin,botAdmin,group,private,prem,wait,error,done}
API utama = APIZ2Z: global.apiz2z='https://apiz2z.web.id'; global.apikeyapiz2z=''  (diisi owner).
Baris terakhir file: module.exports = require('./library/settings-map').settingsMap(global)
library/settings-map.js menerjemahkan global.* jadi object config { bot, owner, prefix, pairing,
license, database, api, plugin, media, limit, ... }. .env (kalau diisi) menimpa nilai settingsbot.
Password bot & nomor bot TIDAK di sini (diatur Developer di web database).


TAHAP 6 - WEB DATABASE (folder server/, PostgreSQL)
---------------------------------------------------
  - server/index.js (Express), server/cli.js (admin), server/migrations/*.sql (append-only,
    dijalankan runner berurutan), server/services/, server/routes/, server/public/ (dashboard),
    server/lib/ (db.js pakai pg Pool, security.js, errors.js, env.js).
  - Tabel inti: ranks, rank_permissions, accounts, bots, bot_credentials, maintenance_settings,
    audit_logs. accounts & bots pakai soft-delete (deleted_at). password_hash bcrypt.
  - ROLE (dari rendah ke tinggi), tiap atasan bisa kelola bawahannya:
      RESELLER  kuota 10 nomor   -> hanya tambah/hapus NOMOR bot miliknya
      SUKI      kuota 50         -> + kelola RESELLER
      KING      kuota 100        -> + kelola SUKI
      CEO       kuota 1000       -> + kelola KING
      DEVELOPER tanpa batas      -> semua: password bot, nyala/mati bot, ganti nama, cabut sesi,
                                    ban/unban, maintenance, ganti rank, audit, backup, lihat semua
    Username & password akun BEBAS (tanpa aturan format). PASSWORD BOT hanya Developer yang buat/
    ganti (tidak ada password otomatis). Reseller dst HANYA tambah/hapus nomor, bukan password.
  - Login web: HANYA username (atau email) + password. TANPA Google / OAuth.
  - API untuk bot: POST /api/bot/auth/login (nomor+password -> token), /api/bot/auth/verify,
    /api/bot/heartbeat, /api/bot/auth/logout. Rate limit per token (banyak bot 1 IP di panel).
  - Keamanan web: cookie session (hashed), CSRF (HMAC + cek Origin), bcrypt, rate limit + lockout,
    header keamanan (CSP, nosniff, dll.). Database mati -> balas 503 DATABASE_UNAVAILABLE (bukan 500).
  - MAINTENANCE 3 lapis (hanya DEVELOPER), prioritas web > per-bot > global:
      web     : non-developer ditolak 503 WEB_MAINTENANCE (API & login), DAN semua bot berhenti
                total (router diam, scheduler stop, startup menunggu, cek ulang tiap 30 detik).
      per-bot : matikan / maintenance satu bot dari dashboard.
      global  : maintenance semua bot sekaligus.
  - cli.js: migrate, status, bootstrap-developer, set-password, login-link (darurat 15 menit),
    add-bot, list-bots, del-bot, set-bot-password, backup (terenkripsi), restore, purge.
