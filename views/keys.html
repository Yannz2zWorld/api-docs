Bikin key baru

6–64 karakter: huruf, angka, _ atau -. Harus unik. Key pendek lebih gampang ditebak — makin panjang makin aman.

Key cuma tampil utuh sekali setelah dibikin (server cuma nyimpen hash-nya). Simpan di password manager atau secret server; jangan taruh di frontend publik.
