API keys

Buat API key

Key hanya bisa mengakses endpoint sampai tier-nya (FREE < SULTAN < SEPUH < DEWA) dan punya kuota harian sendiri sesuai tier itu. Setelah masa aktif habis key ditolak (API_KEY_EXPIRED) sampai diperpanjang.

Nilai key lengkap tidak pernah disimpan (hanya hash SHA-256), jadi tidak bisa ditampilkan lagi — termasuk untuk owner. Tempel key lengkap di pencarian untuk menemukan pemiliknya. Cabut mematikan key tapi menyimpan catatannya; Hapus menghapus key permanen (riwayat pemakaian tetap ada).
