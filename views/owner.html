API keys

Bikin API key

Public: siapa pun yang punya key bisa pakai. Private: server ngecek key dan akun yang lagi login — user lain ditolak walaupun tahu key-nya. Developer: cuma akun developer. Key cuma bisa akses endpoint sampai tier-nya dan punya kuota harian sendiri. Custom key berlaku buat semua jenis dan nggak boleh sama dengan key lain.

Nilai key lengkap nggak pernah disimpan (cuma hash SHA-256), jadi nggak bisa ditampilin lagi — developer juga nggak bisa. Tempel key lengkap di pencarian buat nemuin pemiliknya. Nonaktifkan matiin key sementara (bisa diaktifin lagi); Reset bikin nilai key baru dan key lama langsung nggak berlaku; Cabut matiin key permanen tapi catatannya tetap disimpan; Hapus ngehapus key (riwayat pemakaiannya tetap ada).

Error

Semua error endpoint, dari request asli maupun cek otomatis. Kalau server sumbernya bilang limit plan, kuota/kredit habis, atau key ditolak, endpoint-nya otomatis disembunyikan dari API Docs, Playground, dan status endpoint. Endpoint itu tetap dicek, dan begitu jalan lagi bakal muncul lagi sendiri.

Arti tombol-tombolnya
  • Tampilkan lagi → munculin lagi endpoint yang disembunyikan otomatis. Kalau server sumbernya masih nolak, nanti disembunyikan lagi sendiri.
  • Hapus catatan → cuma ngehapus baris catatan error itu dari daftar ini. Endpoint-nya nggak dihapus atau diubah apa-apa. Kalau error yang sama kejadian lagi, catatannya muncul lagi.
  • Hapus yang udah beres → hapus semua catatan yang endpoint-nya udah jalan lagi (status "udah jalan lagi").

Backup

Jaga-jaga kalau website atau database bermasalah. Simpan file backup di tempat aman dan jangan dibagiin ke siapa pun, isinya data akun.

Backup database

Semua tabel & data (.sql). Ini yang dipakai buat balikin database: jalanin dulu semua migrations/*.sql, terus jalanin file ini di SQL Editor Neon.

Backup file web

Semua kode website (.zip, diambil dari repo GitHub). Kalau web-nya rusak, tinggal upload/deploy ulang isi zip ini.

Backup JSON

Data yang sama kayak backup database, tapi dalam bentuk JSON. Gampang dibuka & dibaca (misal buat cek data user atau pembayaran), tapi bukan buat restore.

Kirim ke Gmail

Backup database (.sql dan JSON) dikirim jadi lampiran ke email developer. File web dikirim berupa link, soalnya Gmail nolak lampiran yang isinya file .js.
