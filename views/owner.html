API keys

Buat API key

Public: siapa pun yang punya key bisa memakai. Private: server mengecek key dan akun yang sedang login — user lain ditolak walau tahu key-nya. Developer: hanya akun developer. Key hanya bisa mengakses endpoint sampai tier-nya dan punya kuota harian sendiri. Custom key berlaku untuk semua jenis dan tidak boleh sama dengan key lain.

Nilai key lengkap tidak pernah disimpan (hanya hash SHA-256), jadi tidak bisa ditampilkan lagi — termasuk untuk developer. Tempel key lengkap di pencarian untuk menemukan pemiliknya. Nonaktifkan mematikan sementara (bisa diaktifkan lagi); Reset membuat nilai key baru dan key lama langsung tidak berlaku; Cabut mematikan permanen tapi menyimpan catatannya; Hapus menghapus key (riwayat pemakaian tetap ada).
